# Cookbooks — External Reference Intake

External implementation references mined into Vidoxlabs-native skills, plugins, and agents.

## Lifecycle

1. **Inbox** — newly captured reference
2. **Reviewing** — evaluating for relevance and quality
3. **Mined** — concept extracted, rewrite in progress
4. **Integrated** — first-party skill or agent created from the concept
5. **Archived** — no longer relevant

## What belongs here

- High-signal repositories and guides
- Example patterns, prompt techniques, agent scaffolds
- References that could inform a Vidoxlabs skill or agent

## Conventions

- Prefer canonical links (repo root) unless a subpath is the meaningful unit
- Notes should be actionable: "extract X pattern", "good eval harness"
- Link the resulting first-party skill when promoted
