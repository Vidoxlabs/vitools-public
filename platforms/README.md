# Platform Install Snippets

Each public skill and agent in the ViTools catalog supports three install
actions. These snippets are generated by `scripts/catalog-build.py` and
stored in `catalog/vitools.catalog.json` under each item's `install` field.

## A. Single-unit install

### Generic (curl/npx)

```bash
npx skills add vidoxlabs/vitools-public/skills/<slug>
```

### Claude Code

```text
/plugin marketplace add Vidoxlabs/vitools-public
# then enable the skill by name
```

### Cursor

```bash
curl -fsSL https://vidoxlabs.dev/vitools/skills/<slug>/raw -o .cursor/skills/<slug>/SKILL.md
```

### Codex / generic agent instruction

```text
Fetch https://vidoxlabs.dev/vitools/skills/<slug>.md and install it as a
project skill at skills/<slug>/SKILL.md. Follow its Procedure. Do not
modify Guardrails.
```

## B. MCP connect

Add this to your MCP client configuration:

```json
{
  "mcpServers": {
    "vidoxlabs-vitools": {
      "url": "https://mcp.vidoxlabs.dev/vitools"
    }
  }
}
```

MCP tools exposed by the worker:

| Tool | Purpose |
|------|---------|
| `vitools.list` | Filter by kind, category, tag, status |
| `vitools.get` | Return one unit's frontmatter + body URL |
| `vitools.categories` | Category counts |
| `vitools.search` | Keyword over name/description/tags |
| `vitools.install_snippet` | Return platform-specific install text |
| `vitools.manifest` | Full catalog hash + version |

All tools are read-only. No write tools on the public MCP.

## C. Download

- Rendered page: `https://vidoxlabs.dev/vitools/skills/<slug>`
- Raw markdown: `https://vidoxlabs.dev/vitools/skills/<slug>/raw`
- Zip folder: `https://vidoxlabs.dev/vitools/skills/<slug>.zip`

The zip includes `SKILL.md` plus any `references/`, `scripts/`, or
`templates/` directories in the skill folder.

## Agents

For agents, replace `skills` with `agents` and `SKILL.md` with `AGENT.md`
in all paths and commands.
