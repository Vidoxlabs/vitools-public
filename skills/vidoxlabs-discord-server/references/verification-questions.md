# Verification & Onboarding Questions

**Purpose**: Gate L3 Public to @Verified or L2 Contributor. Ensures genuine interest in Vidoxlabs (v37, CRS, agents, ViLabs Studio, Memorix) and reduces spam. Use in #rules or a dedicated #verify channel with reaction or form (Google Form + Vibot webhook future, or simple reaction + manual L1 review initially).

**Recommended Flow**:
1. New member joins ’ Vibot DMs welcome + link to #rules.
2. User reads #rules (pinned).
3. User reacts to a specific emoji in #rules or posts in #verify with answers.
4. L1 or Vibot (future auto if form) reviews.
5. Grant @Verified (basic) or @L2-Contributor (if strong contribution signal).
6. Vibot sends congrats DM with tier explanation and next steps (contribute on GitHub for auto-path).

**Sample Questions** (copy into #rules pinned message or verification form):

**Vidoxlabs Verification Questions**

To unlock higher tiers and help us keep the community high-signal, please answer these briefly:

1. What brought you to Vidoxlabs? (e.g. v37 cluster / Proxmox infra, CRS consolidation, Orchestral Autonomous Intelligence / Violet Cabinet, ViLabs Studio + Memorix, agent tooling, or other)

2. Have you visited or starred the Vidoxlabs / vilabs GitHub organization? (Link: https://github.com/vidoxlabs or vilabs meta-repo)

3. Which member of the Violet Cabinet (VIs) or concept interests you most right now? (Violet - Chair/Administrative, Wisteria - Narrative, Xylia - Risk/Boundaries, Yarrow - Coherence/Synthesis, Zinnia - Execution/Sequencing, or LAs / VAs like Verdite)

4. Do you agree to follow server rules, respect compartmentalization (L0-L3), and contribute constructively toward Grand Autonomous Operations and sovereign AI infrastructure?

5. (Optional) Any specific skills or repos you'd like to help with? (e.g. vilabs_cli, v37 hardware, documentation, Python/TS agents, Discord Vibot itself)

**Scoring / Grant Criteria** (L1 manual review initially):
- Genuine answers showing understanding or interest in Vidoxlabs vision (from masternote.md) ’ @Verified + welcome to public channels.
- Evidence of GitHub activity or strong alignment ’ direct @L2-Contributor (or fast-track after small PR/issue).
- Spam / low-effort / off-topic ’ deny or @Verified only with note.
