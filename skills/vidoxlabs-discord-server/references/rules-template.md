# Vidoxlabs Discord Server Rules

**Pinned in #rules  Read before posting or requesting verification.**

## Core Principles (Vidoxlabs Canon)
We operate under **Agentic Data Sovereignty**, **Zero-Hallucination Processing**, **Absolute State Isolation**, and **Algorithmic Determinism**. This server mirrors our compartmentalized architecture (L0-L3 tiers, VIs / LAs separation).

- **L3 Public**: Open community interested in sovereign AI infra, v37 cluster, CRS, agents (Violet Cabinet), ViLabs Studio, Memorix.
- **L2+**: Contributors and moderators with access to dev sync channels (GitHub issues/PRs mirrored).
- **L1+**: Discord admins.
- **L0**: Administrative / ops core (Violet-equivalent). Destructive actions require ratification.

## Rules
1. **Be constructive and high-signal**. No low-effort posts, spam, or off-topic in project channels. Use #off-topic for casual.
2. **Respect tiers and compartmentalization**. Do not attempt to access or discuss L0/L1 content if not authorized. Report issues via L1/L2 channels or Vibot.
3. **No sharing of secrets, credentials, or sensitive v37 config**. Use Infisical pattern. DLP enforced. Violations = immediate removal + possible L0 escalation.
4. **Follow ARKSRRA reasoning for proposals**. Major suggestions should show Analysis, Research, Knowledge, Sequence (or link GitHub issue). Violet / Cabinet ratifies high-impact changes.
5. **GitHub-first for contributions**. Issues, PRs, and discussions in vilabs org take precedence. Discord L2 mirrors for coordination, not replacement.
6. **Respect VIs and LAs**. Violet Cabinet (Violet, Wisteria, Xylia, Yarrow, Zinnia) and Lab Assistants handle orchestration and execution. Vibot is the Discord LA  it executes delegated tasks but does not self-authorize destructive changes.
7. **Verification required for higher access**. Answer questions in #verify or via Vibot to unlock @Verified or L2. Genuine interest in Vidoxlabs vision expected.
8. **No toxicity, harassment, or bad-faith**. Xylia (Risk) enforces boundaries. Violations lead to role removal or ban.
9. **Link back to canonical sources**. When sharing updates, prefer ViDocs, GitHub, or official masternote.md references over unverified claims.
10. **Temporal awareness & patience**. Agents and humans operate with time horizons. Allow reasonable response times; use threads for ongoing discussions.

## Verification & Tiers
See pinned verification questions or use Vibot `/verify` (when available).

Vibot is our official Discord Lab Assistant. Use slash commands for help, role requests (L1+), GitHub sync status, and server info. High-risk actions require explicit confirmation.

## Enforcement
