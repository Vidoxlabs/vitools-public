  verification sub-agents for the ViTools rewrite pipe
- **skill-author**: >-
  Writes a first-party SKILL.md from a concept card or external reference.
  Produces original Vidoxlabs prose with r

  Builds, validates, and maintains the ViTools public catalog. Runs the
